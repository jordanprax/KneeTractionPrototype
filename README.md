# Knee Traction Prototype

## Overview

This project is a force-controlled knee traction prototype built around an ESP32 microcontroller.

The long-term goals are:

- Closed-loop force control
- Stepper motor driven linear actuator
- Load cell feedback
- OLED user interface
- Adjustable force and displacement
- Professional embedded firmware architecture

## Hardware

- ESP32 DevKit V1
- BIGTREETECH TMC2209 Stepper Driver
- NEMA 17 Stepper Motor
- HX711 Load Cell Amplifier (planned)
- S-Beam Load Cell (planned)
- OLED Display (planned)
